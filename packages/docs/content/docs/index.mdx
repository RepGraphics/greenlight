Greenlight Fork is an unofficial Xbox Remote Play and Cloud Gaming desktop client, based on upstream Greenlight.

## Install

Download a successful platform artifact from the [fork installer workflow](https://github.com/RepGraphics/greenlight/actions/workflows/fork-installers.yml) or check [published releases](https://github.com/RepGraphics/greenlight/releases). Development installers may be unsigned.

## Connect

Sign in with your Microsoft account. Enable remote features on your console for Remote Play, or select an entitled Cloud Gaming title.

## Choose a player

Classic is the default. To try V3, select the experimental engine in Settings → Streaming. Start with standard video rendering. V3 includes filters, capture, diagnostics and optional Remote Play recovery.

If your controller is paired directly with the Xbox, enable Controller connected to Xbox in Settings → Input before starting the V3 session.

## Troubleshooting

Compare Classic and V3 when investigating streaming problems. In V3, press F8 to pin the toolbar and export diagnostics. Review attachments for private information before sharing.

Report fork-specific issues in the [fork repository](https://github.com/RepGraphics/greenlight/issues).

See the [README](https://github.com/RepGraphics/greenlight#readme) for detailed features, development instructions and known limitations.
