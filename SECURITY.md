# Security policy

This independently maintained fork is under active development. The current development branch is `main-v2`; no long-term security support or response-time guarantee is offered.

## Reporting a vulnerability

Use [GitHub private vulnerability reporting](https://github.com/RepGraphics/greenlight/security/advisories/new) if enabled. If it is unavailable, request a private contact channel through the repository without disclosing exploit details publicly.

Include the affected build or commit, affected component, impact, reproduction steps and any suggested mitigation. Redact tokens, credentials, personal identifiers and private network information.

Please do not publish sensitive vulnerability details before maintainers have had a reasonable opportunity to investigate. Issues in upstream Greenlight or Microsoft services should be reported to the respective maintainers.

The optional desktop WebUI is intended for local use. Avoid exposing it directly to the internet. Use trusted builds and keep your operating system updated.
